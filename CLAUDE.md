# Claude Code entry point

Read `AGENTS.md` before changing this repository.

For any work involving the webinar, demo flow, checkpoint branches, prepared bug, screenshots, slides, speaker script, repository history, or GitHub state, read [`docs/PROJECT_HANDOFF.md`](docs/PROJECT_HANDOFF.md) before planning or editing.

Treat every `demo/*` branch as an immutable presentation checkpoint. Begin new work from the latest `origin/develop`, create a focused feature branch, verify with the repository scripts, and open a pull request into `develop`.

The GitHub default branch, `main`, currently contains only the initialization commit. The complete application is on `develop`. Do not diagnose the missing `package.json` on `main` as an npm problem.
