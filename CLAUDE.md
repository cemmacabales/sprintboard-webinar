# Claude Code entry point

**Start with [`docs/NEXT_SESSION.md`](docs/NEXT_SESSION.md)**: current state, verified facts, and the task in progress.

Read `AGENTS.md` before changing this repository.

For any work involving the webinar, demo flow, checkpoint branches, prepared bug, screenshots, slides, speaker script, repository history, or GitHub state, read [`docs/PROJECT_HANDOFF.md`](docs/PROJECT_HANDOFF.md) before planning or editing.

Treat every `demo/*` branch as an immutable presentation checkpoint. Begin new work from the latest `origin/main`, create a focused branch, verify with the repository scripts, and open a pull request into `main`.

`main` is the default branch and contains the complete application. `demo/needs-work` is the deliberately broken demo state; never merge into it.
