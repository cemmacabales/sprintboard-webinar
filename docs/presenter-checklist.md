# Presenter checklist

## Before the session

- [ ] Install dependencies with `npm ci`.
- [ ] Run `npm run test:run`, `npm run lint`, and `npm run build`.
- [ ] Confirm the prepared crash reproduces on `demo/start` and `demo/feature-complete`.
- [ ] Confirm the bug no longer reproduces on `demo/bug-fixed` and `demo/final`.
- [ ] Confirm the start and final screenshots match the current UI.
- [ ] Open SprintBoard in the Codex built-in browser.
- [ ] Prepare the slide deck.
- [ ] Open `docs/webinar-prompts.md` for copying.
- [ ] Disable notifications.
- [ ] Close unrelated repositories and private tabs.
- [ ] Confirm the selected Codex model and reasoning level.
- [ ] Confirm the task is using Local.
- [ ] Open the prepared Worktree task.
- [ ] Confirm every checkpoint branch exists locally and remotely.
- [ ] Record a 60–90 second backup clip.

## Fast recovery

- [ ] Keep a terminal ready at the repository root.
- [ ] Know the next checkpoint branch in the demo sequence.
- [ ] If a live step fails, explain the intended outcome and switch to that checkpoint.
