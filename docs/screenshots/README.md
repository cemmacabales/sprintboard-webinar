# Screenshot checklist

Capture both images at a 1440 × 1000 desktop viewport with the browser chrome excluded.

## `start.png`

1. Switch to `demo/start`.
2. Run `npm ci` and `npm run dev`.
3. Open `/?filter=all`.
4. Keep every details panel closed and capture the full dashboard.

## `final.png`

1. Switch to `demo/final`.
2. Run `npm ci` and `npm run dev`.
3. Open `/?filter=at-risk`.
4. Keep every details panel closed and capture the full dashboard with the At risk control selected.

After adding the images, confirm the README links render and amend only the final checkpoint commit if you want the supplied branch hashes to remain a linear four-step sequence.
